## 1. 서론

### 1.1 문서 목적 및 범위
본 문서의 목적은 클라우드 기반 파일 공유 시스템인 'Mini Drive'에 대한 테스팅 설계를 수행하고 그 결과를 나타내는 데 있다. 본 문서에서는 해당 프로젝트의 테스트 기준, 테스트 범위, 주요 기능별 테스트 케이스 및 예상/실제 테스트 결과를 명시한다.

### 1.2 프로젝트 개요
사용자가 클라우드 환경에 파일을 업로드 및 다운로드하고, 링크 또는 권한 설정을 통해 다른 사용자와 파일을 안전하게 공유할 수 있는 웹 기반의 클라우드 파일 공유 시스템(Mini Drive)을 구축한다.

### 1.3 용어 정의
| 용어 | 설명 |
|:---|:---|
| 서버사이드 | 서버 측 시스템을 뜻하며, 본 프로젝트에서는 회원 정보 데이터베이스, 파일 스토리지 관리 및 연산 기능을 수행한다. |
| 클라이언트 | 사용자 눈에 보이는 시스템을 뜻하며, 사용자가 파일을 관리할 수 있는 웹 브라우저 인터페이스를 뜻한다. |
| 공유 권한 | 특정 파일에 대해 타 사용자가 접근(읽기, 쓰기 등)할 수 있도록 허용하는 권한 설정. |

2) 품질 요구사항 명세서: `quality_factors.md`

## 2. 테스트 개요

### 2.1 테스트 범위
테스트는 시스템의 세부적인 내부 로직을 모른다는 가정 하에 **블랙박스 테스트(Black-box Test)** 로 이루어진다.

| 범위 | 내용 |
|:---|:---|
| Web 기반 시스템 | Ⅰ. 브라우저/서버사이드 파일 입출력 동작 정확성 확인<br>Ⅱ. UI/UX 및 요구사항 충족 확인 |
| Database / Storage | Ⅰ. 웹 프론트엔드와 파일 스토리지 간 연동 시험<br>Ⅱ. 사용자 정보 및 접근 권한 데이터 입출력 확인 |

### 2.2 테스트 항목 및 통과 기준

**[기능별 테스트 항목]**
| 기능별 테스트 항목 | 통과 기준 |
|:---|:---|
| 회원가입 및 로그인 | 이메일/비밀번호가 일치하는 올바른 회원정보만이 시스템에 접근할 수 있다. |
| 파일 업로드 | 허용된 확장자와 용량 내의 파일이 개인 스토리지 공간에 정상적으로 업로드된다. |
| 파일 다운로드 | 스토리지에 존재하는 파일을 원본 손실 없이 로컬 환경으로 다운로드할 수 있다. |
| 파일 공유 | 권한이 부여된 사용자 또는 유효한 공유 링크를 통해서만 해당 파일에 접근할 수 있다. |

**[비기능별 테스트 항목]**
| 비기능별 테스트 항목 | 통과 기준 |
|:---|:---|
| 브라우저 호환성 | Chrome, Edge, Safari 등 다수의 브라우저에서 웹 시스템이 정상 작동한다. |
| 보안 테스트 | 로그인하지 않거나 권한이 없는 사용자는 타인의 파일 디렉토리에 접근할 수 없다. |
